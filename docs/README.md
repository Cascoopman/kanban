# Engineering Docs

This folder is the starting point for engineers working on Kanban itself.

This folder contains stable onboarding, architecture, and operational references for engineers working on Kanban.

- `README.md` explains the product, local setup, and everyday usage.
- `docs/` holds stable onboarding, architecture, and troubleshooting references.

If you are new to the codebase, read these in order:

1. [`../README.md`](../README.md) for the product overview and local setup.
2. [`architecture.md`](./architecture.md) for the system map, runtime model, and key file guide.
3. [`task-dependencies.md`](./task-dependencies.md) for dependency semantics, validation, and persistence behavior.

When adding engineering docs, keep durable explanations here and use issues or pull requests for temporary plans and handoffs.
